# Workflow

1. 运行百度网盘环境诊断，确认 bdpan CLI、登录状态和目标书库目录可用。
2. 列出数据库中状态为 available 或 failed 的百度网盘下载任务。
3. 要求用户确认实际下载范围和目标目录。
4. 对每个分享链接传入已解析的提取码，将文件下载到隔离临时目录。
5. 将成功文件以不覆盖策略归档到对应书籍目录，并更新任务状态和本地路径。
6. 保留失败任务及错误状态，输出可重试的汇总结果。

## Guardrails

- 不得保存或输出 OAuth 凭据、授权码或密码。
- 不得覆盖既有用户文件。
- 不得自动启用系统功能、安装 WSL 或重启远程主机。
- 仅在用户明确确认后执行会产生网盘转存或下载的命令。
