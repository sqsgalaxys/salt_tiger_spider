# Workflow

1. 先运行环境诊断，确认 bdpan CLI 或受支持的 WSL 环境可用。
2. 确认用户已完成官方 OAuth 登录，再处理分享链接。
3. 仅处理数据库中状态为 available 或 failed 的任务，并要求用户确认下载操作。
4. 将分享链接和提取码传给 bdpan CLI，下载到每本书专用的隔离临时目录。
5. 验证下载结果后，以不覆盖策略归档到对应书籍目录。
6. 成功后记录本地路径和 synced 状态；失败时记录 failed 状态以便后续重试。

## Guardrails

- 不保存、显示或代填账号凭据和授权码。
- 不覆盖既有书籍文件；发生同名冲突时保留两份并使用稳定区分名。
- 不将分享链接视为普通直链，也不绕过提取码、登录或访问限制。
- 不在环境诊断或安装失败后继续执行系统级修改。
